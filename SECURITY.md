# Security / Безопасность

**EN.** Supported version: the latest release. Report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/George-Salt/fakepanic/security/advisories/new).
Include the version, reproduction steps and impact. Do not publish tokens or personal logs.
Fake Panic runs as your user. It needs no root privileges for playback. Game mode launches
Gamescope and injects input only into its nested X11 session; it is experimental.

**RU.** Поддерживается последний релиз. Об уязвимостях сообщайте приватно через
[GitHub](https://github.com/George-Salt/fakepanic/security/advisories/new).
Укажите версию, шаги воспроизведения и последствия. Не публикуйте токены и личные логи.
Fake Panic работает от обычного пользователя. Для воспроизведения root не нужен.
Игровой режим запускает Gamescope и передаёт ввод в его вложенный сеанс X11; режим экспериментальный.
